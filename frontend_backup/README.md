# Euroace - Dia da Europa

Frontend desenvolvido em React + TypeScript + CSS, pronto para abrir no VS Code.

## Como executar

```bash
npm install
npm run dev
```

Depois aceda ao endereço mostrado no terminal, normalmente `http://localhost:5173`.

## Compilar para produção

```bash
npm run build
```

A versão final fica na pasta `dist/`.

## Estrutura

```txt
src/
├── App.tsx
├── main.tsx
├── styles.css
└── assets/images/
    ├── header.png
    └── footer.png
```
